# Legacy research — not a source of truth

This directory preserves the original coursework, experimental notebooks, prototype modules, and QuantConnect
draft with their Git history. They contain known execution, overlap, cost, time-zone, selection-bias, and test-set
reuse problems. Do not cite their displayed performance.

The maintained implementation lives in `cross_market/`; versioned conclusions live in `outputs/portfolio/`.

Original research was co-authored with [@AlexSamuseva](https://github.com/AlexSamuseva). The repository remains a
GitHub fork so the upstream lineage and commit authorship are visible.
